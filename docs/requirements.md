# 功能和交互

## 滚动截图

入口在 App 首页、控制中心主控制和灵动岛。首次引导解释照片权限、控制中心添加方法和全屏共享。系统确认之前不采集；确认后等待系统面板收起，在目标页面沿选定的纵向或横向缓慢滚动。同一轴可往返，算法按内容位置去重。图片处理和帧缓存均在本机。

“接下一页”暂停当前流；换页后点“继续”，明确的新页面作为新段拼接。点击“完成”、再次点击主控制或系统正常停止后，封存素材，自动整理并保存。拒绝照片权限时保留成品，在作品中可重试保存。相册写入结果不确定时停止自动写入并提示检查，避免重复照片。

完成后显示缩略图，可查看完整作品、保存或分享。每次录制使用独立存储目录。中断、尺寸变化、无法可靠拼接或资源不足时，不把局部输出称为完整结果。允许对完整封存的输入重试计算；失败缓存不能阻止重新计算。

## 多图拼接

系统照片选择器接收 2–20 张本机图片；失败项目需要移除或重新选择。支持调整顺序、裁剪、宽度、0/8/16/24 像素间距、黑白背景和撤销。生成 PNG 或 JPEG 后再选择保存或系统分享。

输入单图上限 4800 万像素；输出上限宽 2160 像素、高 32000 像素、2400 万像素。超出预算时提出缩小方案，由用户确认；取消、导入失败或中断时保留已提交的素材与编辑记录。当前拼图在最后一次确认操作 24 小时后可被清理，正在使用时延后。长期保存请导出到相册或文件。

## 调休闹钟

最多 8 条规则，可选择法定工作日、每天或自选星期，单日例外优先。启用规则不能占用相同时间。所有显示和计算固定为北京时间，不随旅行地时区改变。

法定工作日先看年度覆盖表中的休息/补班，再按普通周一至周五判断。缺失年度时显示未知，不猜测；每天、自选星期和明确单日例外不依赖年度文件。使用 AlarmKit 的绝对时间排程，先持久化意图，再操作系统并回读确认。关闭、删除或修改时撤销旧事件；不取消其他来源的系统闹钟。

首页显示实际确认的下一次事件、覆盖和异常；年度安排页显示来源、版本、内置/下载状态和更新入口。自动检查可关闭。排程窗口有限，后台机会不确定，用户需要定期打开 App 并检查覆盖日期。
