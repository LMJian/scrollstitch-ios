隐私与数据

你的内容，留在本机。

本政策适用于卷轴 iPhone App 的滚动截图、多图拼接与调休闹钟。开发者：李明健。更新日期：2026-10-27。

图片留在本机

卷轴在本机处理你选择的图片和录屏画面，不向开发者服务器上传素材，也不接入广告或统计服务。

录屏与声音

开始前由 Apple 确认共享整个屏幕。画面可能包含通知和当前页面内容。卷轴只在本机录制和处理画面，不采集声音，不申请麦克风权限。

选图与保存

多图拼接通过系统照片选择器接收你选中的图片。滚动截图在首次引导时请求仅添加照片权限，完成后自动保存；多图拼接由你点击保存。不要求读取整个相册。拒绝照片权限后，滚动成品仍保留在作品列表，多图拼接仍可使用系统分享。

继续制作与清理

每次滚动截图分别保留为本机作品，新建不会清理已有滚动作品和原始素材。多图拼接保留一个当前编辑作品，其素材在最后一次确认操作 24 小时后可被清理，正在使用时延后。清除本机编辑作品不会删除相册原图和已保存图片。

分享和诊断

图片分享由你选择接收应用。诊断文件仅在你操作时生成和分享，包含任务状态、画面顺序、尺寸、摘要与处理耗时，不含图像内容和文件路径。系统相册同步及接收应用的处理由你的设置和对应服务决定。

调休闹钟与年度下载

闹钟设置与单日例外保存在本机，响铃由 Apple 系统闹钟执行。进入闹钟功能后可通过 HTTPS 下载 GitHub Pages 的公开年度安排，也可关闭自动检查。请求不附带你的闹钟、日程或图片；下载失败时保留已有有效数据。所有时间均按北京时间计算。

网络请求与托管服务

年度安排由 GitHub Pages 提供。下载时，托管服务会接收 IP 地址、请求时间、请求路径及网络客户端信息；GitHub 说明会为安全目的记录访问者 IP。卷轴不在请求中附带图片、录屏、闹钟、设备唯一标识或账户信息，不设置分析或广告 Cookie。可在年度安排中关闭自动检查；手动检查仍会发起网络请求。

删除与保留

可在应用中清除当前拼图或删除闹钟。滚动作品与素材目前保留在本机；如需清理全部本机数据，请先导出需要保留的结果再卸载应用。相册里的成品和你自行分享的副本不会随之删除。系统备份及托管服务日志由相应服务政策决定。

联系开发者

你的选择与隐私请求

可在 iOS 设置中管理录屏、添加照片、通知和闹钟相关权限，在年度安排中关闭自动检查，并在 App 中管理本机作品与闹钟。离线处理不要求注册账号。

如需了解、纠正或删除你主动发送给开发者的反馈资料，请联系 limingjian.yy@gmail.com。本机素材不会自动上传，因此开发者无法在服务器替你读取或删除这些本机文件。处理支持请求后不再主动使用相关资料；法律要求、必要的争议处理和邮件服务备份可能影响最终删除时间。

托管服务与政策更新

本支持网站及年度 JSON 文件由 GitHub Pages 托管，网络请求可能经过境外服务。GitHub 会为安全目的记录访问者 IP；我们不向年度下载接口附加账号、图片或闹钟内容，也不部署广告、跟踪脚本或分析 Cookie。

可查阅 GitHub Pages 数据收集说明及 GitHub 隐私声明。如数据处理方式发生变化，会同步更新 App 内说明和本页，并按适用要求提供提示或征求同意。
